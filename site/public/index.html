Windows Verification

Install & Verify v0.1.0-rc.1 in 3 Steps

Reproducible GitHub Actions builds publish SHA-256 checksums for every Windows artifact. Verify the digest before executing the installer.

Unsigned Pre-Release Notice: v0.1.0-rc.1 Windows installers are currently unsigned prior to SignPath Foundation free OSS code signing onboarding (planned once v0.1.0 is tagged). Windows SmartScreen may warn on first run—always match the SHA-256 digest below.
  1. 01

    Download the Installer

    Grab either the MSI package or NSIS setup executable from the official GitHub release:

    • Oudos_0.1.0_x64_en-US.msi
    • Oudos_0.1.0_x64-setup.exe
    • SHA256SUMS-windows.txt
  2. 02

    Verify SHA-256 in PowerShell

    Run Get-FileHash in your Downloads directory and confirm the hash matches the published v0.1.0-rc.1 digests verbatim:

    PowerShell 
    Get-FileHash "$HOME\Downloads\Oudos_0.1.0_x64_en-US.msi" -Algorithm SHA256
Get-FileHash "$HOME\Downloads\Oudos_0.1.0_x64-setup.exe" -Algorithm SHA256
    Artifact Expected SHA-256 (v0.1.0-rc.1)
    Oudos_0.1.0_x64_en-US.msi 4c5dbb2b9cbcd85c6c461799245719e0bb249fd2e61757ed2ad206ff549075a2
    Oudos_0.1.0_x64-setup.exe 8bd4ae629fc437cf1ae3b9e3166beecd7c4182c9c530bdc1b9a781f74c198c6f
  3. 03

    Run Your First Asks-First Session

    On incoming requests, Oudos enforces four concrete safeguards before any pixel leaves your machine:

    • 5-second cooling-off timer disables Allow for first-time requesters alongside a plain-English bank/refund/virus warning.
    • Local 6-digit SAS match derived independently via HKDF-SHA256—never generated or seen by the server.
    • Screen-only defaults: mouse & keyboard, clipboard sync, and file transfer all start OFF.
    • Persistent LIVE banner stays above all windows with local-input-only Stop input and End session controls.

Self-Hosting (deploy/docker-compose.yml)

Run the Full Control Plane in Under 3 Minutes

Zero paywalled tabs. Every command and environment variable below matches deploy/docker-compose.yml and deploy/.env.example verbatim.

1. Base Stack (Direct P2P WebRTC)

Copies deploy/.env.example, builds oud-server + web-pwa, and exposes the console on http://localhost:8080.

Bash 
cp deploy/.env.example deploy/.env
docker compose -f deploy/docker-compose.yml up -d --build
curl -fsS http://localhost:8080/health

2. Optional Compose Profiles

Enable automatic Caddy HTTPS (deploy/Caddyfile, requires OUD_SERVER_DOMAIN) or self-hosted coturn TURN relay fallback:

Caddy HTTPS (--profile tls) 
docker compose -f deploy/docker-compose.yml --profile tls up -d --build
Self-Hosted TURN (--profile coturn) 
docker compose -f deploy/docker-compose.yml --profile coturn up -d --build

Using a Cloudflare Tunnel (cloudflared)? Run the base stack without --profile tls, point your tunnel ingress to http://localhost:8080, and set OUD_SERVER_DOMAIN in deploy/.env to your custom hostname (no https:// prefix).

Environment Variables (deploy/docker-compose.yml & deploy/.env.example)

Variable Default Purpose
OUD_SERVER_DOMAIN localhost Raw domain displayed on Windows host consent cards (no https://) and used by Caddy / coturn realm.
OUD_HTTP_PORT 8080 Host port mapped to web-pwa container port 80.
OUD_BIND_ADDR 0.0.0.0:8080 Internal listen address for oud-server inside Compose.
OUD_DB_PATH /var/lib/oudos/oudos.db SQLite database path persisted in the oudos_data volume.

OUD_SERVER_SEED_HEX "" Optional 64-hex-char Ed25519 seed; leave empty to auto-generate on first boot.

OUD_STUN_URL stun:stun.cloudflare.com:3478 Public STUN endpoint used for direct P2P WebRTC NAT traversal.

Threat Posture & Scope

How Oudos Differs & Honest v0.1.0-rc.1 Status

Oudos is engineered to disrupt rushed phone-scam scripts, enforce host-side permissions, and preserve tamper-evident audit logs. No remote-access software can eliminate social engineering—we document exact boundaries instead of making absolutist claims.

Capability Typical Remote Desktop Tools Oudos (v0.1.0-rc.1)
Consent Model Unattended passwords or full-control defaults common Strictly Asks-First: No unattended mode, no "Until I turn it off" grants; screen-view only by default.
Anti-Coercion Cooling-Off Immediate one-click accept 5-second disabled Allow + plain-English bank, refund, and virus phone-scam warning for first-time requesters.
Anti-Spoofing & Code Match Server-generated PINs or unpinned relay labels Pre-paired server key enrollment with raw domain chip (or amber Personal / Unverified) + local 6-digit HKDF-SHA256 SAS.
Input & Prompt Protection Remote pointer can often interact with host UI Host-enforced SessionGrant gatekeeper + Win32 synthetic input rejection and rect blocking over consent/banner windows.
Screen Blanking Supported ("curtain mode") on host Explicitly disabled in v0.1 so device owners always see what happens on their screen.
Self-Hosting & Licensing Proprietary server or paywalled audit/policy tiers 100% GNU AGPL-3.0: Single docker compose stack includes devices, 15-minute support links, monotonic policies, and hash-chained CSV audit logs.
